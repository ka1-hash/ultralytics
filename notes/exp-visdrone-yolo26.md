# VisDrone YOLO26 实验记录

## 实验环境

- **硬件配置**: NVIDIA GeForce RTX 4080 (16GB) × 2
- **Python版本**: 3.12.10
- **PyTorch版本**: 2.6.0+cu124
- **Ultralytics版本**: 8.4.37
- **数据集**: VisDrone (训练集: 6471张, 验证集: 548张, 10个类别)
- **输入尺寸**: 1280×1280
- **优化器**: MuSGD (lr=0.01, momentum=0.937)
- **数据增强** (Ultralytics default.yaml):
  - Mosaic (`mosaic=1.0`, 概率100%)
  - RandAugment (`auto_augment=randaugment`)
  - HSV颜色增强 (`hsv_h=0.015, hsv_s=0.7, hsv_v=0.4`)
  - 水平翻转 (`fliplr=0.5`)
  - 随机擦除 (`erasing=0.4`)
  - 平移、缩放等几何变换 (`translate=0.1, scale=0.5`)

### 与实验2对比

| 指标 | 实验2 (bs4+ms0.5) | 实验3 (bs8+ms0.0) | 差异 |
|------|-------------------|-------------------|------|
| **mAP50-95** | 0.354 | **0.360** | +0.006 |
| **mAP50** | 0.564 | **0.574** | +0.010 |
| **Precision** | 0.649 | **0.660** | +0.011 |
| **Recall** | 0.543 | **0.559** | +0.016 |
| **训练轮数** | 50 | 73 | +23 |
| **每epoch时长** | ~7分15秒 | ~4分33秒 | 更快 |

> **关于batch size的影响**: Ultralytics 通过梯度累积保证等效batch size一致 (`nbs=64`)。
> - 实验2: accumulate = round(64/4) = 16, 等效batch = 4×16 = 64
> - 实验3: accumulate = round(64/8) = 8, 等效batch = 8×8 = 64
>
> 因此 batch 4→8 不影响优化行为，只是训练速度更快。实验2与实验3的差异仅来自 **multi_scale** 和 **cos_lr** 两个变量。

实验3相比实验2，mAP50-95提升0.6个百分点，Recall提升明显(+1.6%)。关闭multi_scale并启用cosine lr衰减带来了更好的结果，但两者混变无法单独归因。建议后续用控制变量法单独验证multi_scale的影响。

## 实验4: YOLO26m-p2 (双卡DDP, P2小目标检测层)

### 配置参数

```bash
DATA="VisDrone"
MODEL="yolo26m-p2"   # 增加P2检测头，4个检测层
BATCH=4              # 总batch size (每张卡2)
DEVICE="2,3"         # 双GPU DDP训练 (CUDA:2,3)
CACHE=disk           # 使用磁盘缓存
WORKERS=8            # 每卡8个线程,共16个
EPOCHS=120
PATIENCE=20
IMG_SIZE=1280
MULTI_SCALE=0.0      # 关闭多尺度训练
OPTIMIZER="MuSGD"
LR0=0.01
COS_LR=True          # 启用余弦学习率衰减
```

### 与实验3的主要差异

| 参数 | 实验3 | 实验4 |
|------|-------|-------|
| **模型** | yolo26m (3检测层) | yolo26m-p2 (4检测层, 增加P2) |
| **batch** | 8 | 4 |
| **检测层** | P3/P4/P5 | **P2/P3/P4/P5** |
| **每epoch迭代次数** | 809 | 1618 (2倍，因batch减半) |

> batch 4 vs 8 不影响优化行为（梯度累积保证等效batch=64），但batch=4时每epoch迭代数翻倍，训练更慢。

### 模型信息

- **参数量**: 21.1M parameters (比yolo26m的21.8M略少，因P2层仅128通道，P3 从 concat backbone P3 变成了 concat head P2)
- **计算量**: 90.1 GFLOPs (比yolo26m的74.8 GFLOPs增加20.5%，因P2层特征图分辨率大，计算量高)
- **层数**: 349 layers
- **预训练权重**: YOLO26m (COCO, 转移946/962项)
- **检测头**: 4个检测层 [128, 256, 512, 512]，额外P2层(160×160)用于小目标检测

### OOM问题

训练过程中 `TaskAlignedAssigner` 频繁触发 CUDA OOM，自动fallback到CPU计算（共出现约10次）。这是因为P2层输出分辨率(160×160)远大于P3(80×80)，anchor数量大幅增加导致显存不足。建议后续考虑减小batch或使用gradient checkpointing。
