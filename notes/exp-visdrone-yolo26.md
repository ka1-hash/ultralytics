# VisDrone YOLO26 实验记录

## 实验环境

- **硬件配置**: NVIDIA GeForce RTX 4080 (16GB) × 2
- **Python版本**: 3.12.10
- **PyTorch版本**: 2.6.0+cu124
- **Ultralytics版本**: 8.4.37
- **数据集**: VisDrone (训练集: 6471张, 验证集: 548张, 10个类别)
- **输入尺寸**: 1280×1280
- **优化器**: MuSGD (lr=0.01, momentum=0.937)
- **数据增强**: 
  - **显式配置**: Multi-scale (`multi_scale=0.5`)
  - **默认启用** (Ultralytics default.yaml):
    - Mosaic (`mosaic=1.0`, 概率100%)
    - RandAugment (`auto_augment=randaugment`)
    - HSV颜色增强 (`hsv_h=0.015, hsv_s=0.7, hsv_v=0.4`)
    - 水平翻转 (`fliplr=0.5`)
    - 随机擦除 (`erasing=0.4`)
    - 平移、缩放等几何变换 (`translate=0.1, scale=0.5`)

## 实验1: YOLO26n (单卡训练)

### 配置参数

```bash
DATA="VisDrone"
MODEL="yolo26n"
BATCH=4          # 单卡 batch size
DEVICE="3"       # 单GPU (CUDA:3)
CACHE=False      # 不使用RAM缓存
WORKERS=8        # 数据加载线程数
EPOCHS=120
PATIENCE=10      # 早停耐心值
IMG_SIZE=1280
MULTI_SCALE=0.5  # 多尺度训练
OPTIMIZER="MuSGD"
LR0=0.01
COS_LR=False
```

### 模型信息

- **模型大小**: 2.5M parameters
- **计算量**: 5.8 GFLOPs
- **层数**: 260 layers

## 实验2: YOLO26m (双卡DDP训练)

### 配置参数

```bash
DATA="VisDrone"
MODEL="yolo26m"
BATCH=4          # 总batch size (每张卡2)
DEVICE="0,1"     # 双GPU DDP训练
CACHE=True       # 初始使用RAM缓存 (曾导致OOM)
WORKERS=8        # 每卡8个线程,共16个
EPOCHS=120
PATIENCE=10
IMG_SIZE=1280
MULTI_SCALE=0.5
OPTIMIZER="MuSGD"
LR0=0.01
COS_LR=False
```

### 模型信息

- **模型大小**: 21.8M parameters
- **计算量**: 74.8 GFLOPs
- **层数**: 280 layers
- **预训练权重**: YOLO26m (COCO)

### 训练性能与结果
由于首次训练在 Epoch 33 因 RAM 缓存过大导致 OOM（Linux 内核杀进程），随后使用 `cache='disk'` 并从 checkpoint 恢复训练，最终顺利完成。  
训练在第 50 epoch 因早停机制结束（连续 10 个 epoch 无提升），未跑满 120 epoch。

| 指标 | 数值 |
|------|------|
| **总训练时长** | ~6.0 小时 (50 epochs) |
| **实际训练轮数** | 50 / 120 |
| **平均每epoch** | ~7分15秒 (训练+验证) |
| **触发早停** | ✅ 是 (Epoch 40为最佳) |

### 最终结果 (Best Epoch 40)

| 指标 | 数值 |
|------|------|
| **mAP50-95** | **0.354** |
| **mAP50** | **0.564** |
| **Precision** | 0.649 |
| **Recall** | 0.543 |

- **总计**: ~3.4ms per image (~294 FPS)

### 训练曲线分析 (前 40 epoch)
- 前期(1-10 epoch): mAP50-95 从 0.250 → 0.310，快速提升  
- 中期(10-20 epoch): 稳定增长至 0.332  
- 后期(20-40 epoch): 增速趋缓，最高至 0.354，未出现过拟合  

### 崩溃原因简述
首次训练因 `cache=True` 将全部图像加载至 RAM，导致训练集+验证集占用约 21GB 内存，加上 DDP 多进程开销触发 OOM。后续改为 `cache='disk'` 并恢复训练，顺利完成。
